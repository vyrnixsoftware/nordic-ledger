# Operations – how the channel runs without the owner

## Roles
- Claude (this assistant): research, scripts, editorial variation, fact-checking against sources, thumbnails/titles,
  metadata, analytics review, sponsor outreach drafts, policy monitoring. Writes new scripts into `scripts/`.
- Machine (owner's VM or VPS): `pipeline/schedule.py` on cron produces + uploads/schedules the next script.
- Owner: one-time account setup, payments, signatures. Otherwise nothing.

## Owner one-time checklist (only things nobody else can legally do)
1. Google account → YouTube channel "The Nordic Ledger" → AdSense linked, 2FA on.
2. (Recommended) ElevenLabs Creator plan; put key in `~/.profile` as ELEVENLABS_API_KEY. Otherwise offline Piper voice is used.
3. Either: keep the Claude desktop app open with the `nordic-ledger` folder connected (Claude runs the machine steps via device_bash
   and uploads via Chrome), or: give Claude a VPS (Ubuntu, 2 vCPU/4 GB) — install with `./install.sh`, cron `schedule.py`.
4. For API uploads: Google Cloud project → YouTube Data API v3 → OAuth desktop client → `client_secret.json` into `~/.nordic-ledger/`
   → `python3 pipeline/upload.py --auth`. Note: unverified API projects force uploads to *private*; either request the
   YouTube API audit (form, ~1–2 weeks) or let Claude upload through the browser until then.
5. YPP application when 1,000 subs + 4,000 h — Claude will say when; the owner clicks "apply".

## Cadence & guardrails (from the plan)
- 2 uploads/week (Tue/Fri 15:00 UTC), hard cap 3 – enforced in schedule.py.
- Every script must pass `compliance_check`: sources list, chapters, ≥4 scene types, no clichés, scene length limits.
- Description always contains: chapters, "How this video was made" (AI disclosure), numbered sources, disclosure line.
- `synthetic_label: true` in a script's front matter if realistic generated footage of real people/events is used (never by default).
- No third-party footage/music in v1 – all visuals are generated by the pipeline; b-roll added later only with licence.

## Monthly report to owner
Views, watch time, RPM, subs, top videos, next month's topics, any decision needing a signature. Nothing else.
