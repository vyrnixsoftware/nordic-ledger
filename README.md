# The Nordic Ledger

Documentaries on how European and Nordic companies rise, fall and get caught. YouTube: [@TheNordicLedger](https://www.youtube.com/@TheNordicLedger)

This repository is the whole production line, in the open:

- `scripts/` – every episode's script with scene markers, data blocks and a numbered source list
- `pipeline/` – parser → TTS → renderer (Pillow + ffmpeg) → thumbnails → metadata/subtitles → (optional) API upload
- `.github/workflows/build.yml` – GitHub Actions builds each unbuilt script and attaches the finished video + metadata to a release `v<id>-<slug>`
- `channel/` – About text, description template, sponsor policy
- `backlog.csv` – upcoming topics, scored

How videos are made: scripts are researched, written and edited with human editorial judgement, using AI tools to assist with research and drafting; narration is an AI voice; all visuals are generated by the renderer from the script's data. Every video lists its sources.

Local build: `bash bootstrap-assets.sh && python3 pipeline/run.py scripts/001-northvolt.md`
